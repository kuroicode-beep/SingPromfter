## 1. 데이터 스키마

### 1.1 recordings.json — schemaVersion 1 → 2

`RecordingTake` 추가 필드 (전부 additive, 결측 시 기본값):

| 필드 | 타입 | 기본 | 의미 |
|---|---|---|---|
| sourceAudioPath | String? | null | 녹음 당시 실제 재생 파일(변형본 포함) 절대경로 |
| tempoScale | double | 1.0 | 녹음 당시 템포 배율 (메타·재컷용) |
| accompanimentFileName | String? | null | 잘라낸 반주 조각 `<take.id>_acc.m4a` (data/recordings 안) |
| mixBalance | double | 0.5 | 믹스 보컬/반주 밸런스 (0=반주만, 1=보컬만) |
| reverbPreset | String | 'none' | none·karaoke·hall·studio |
| noiseReduction | bool | false | 보컬 체인 afftdn 적용 |
| separatedFileName | String? | null | 분리 서버로 정리한 보컬 `<take.id>_sep.wav` |

- 버전 가드: `version > schemaVersion`일 때만 거부(기존 정책). v1 파일은 그대로 읽힘.
- `remove()`는 fileName + accompanimentFileName + mixedFileName + separatedFileName 모두 삭제.

## 2. 외부 API 계약 (실측 2026-08-08)

### 2.1 작곡 게이트웨이 :8774 (보컬곡 — ACE-Step 1.5 터보)

- `GET /status` → `{ok, server, port:8774}`
- `GET /api/song/engine` → `{ok, alive, base, stats}` — 엔진(:8001) 헬스
- `POST /api/song/generate` → `{ok, job_id}`
  - body: `{prompt(영문 필수), lyrics, duration(180~600 하드), genre, vocal(female|male|duet|choir), bpm?, seed(-1=랜덤), format:"mp3"|"wav", lang:"ko"}`
  - 400: 프롬프트 없음 / 길이 범위 밖
- `GET /api/song/status/{job_id}` → `{status:"queued"|"running"|"done"|"error", detail(한국어, VRAM 순번 포함), elapsed_sec, result:{path,filename,duration,seed}|null, error|null}` — 404: 서버 재시작으로 잡 소실
- `GET /output?path=<절대경로>` — `D:\saw outputs\sound\song\` 내부만 허용. 산출물 보존됨.
- 잡 타임아웃 20분, VRAM lease로 GPU 직렬화.

### 2.2 BGM 서버 :8766 (BGM — MusicGen, 블로킹)

- `GET /status`, `GET /presets` → `[{name, description, base_prompt, recommended_duration, …}]`
- `POST /generate` (블로킹, 수 분): `{prompt, preset, duration(≤300), model_size:"small|medium|large", seed, convert_mp3:true, backend:"musicgen", normalize, fade_in, fade_out}` → `{ok, filename, wav_path|null, mp3_path|null, seed, duration, gen_time}`
- `GET /output?path=` — **생성 직후 이전 출력 전부 삭제되므로 응답 즉시 다운로드 필수**
- 앱 타임아웃 20분. acestep 백엔드는 사용하지 않음(8774가 대체).

### 2.3 Ollama :11434

- `GET /api/tags` → 설치 모델 목록 (모델 존재 검증)
- `POST /api/chat` `{model, messages, stream:false}` → `{message:{content}}` — 타임아웃 120초
- 시스템 프롬프트(스타일): "한국어 곡 설명을 음악 생성 모델용 영어 프롬프트로 변환. 장르·분위기·악기·템포·보컬 타입을 쉼표 나열로만 출력."
- 가사 태깅(옵션): 한국어 가사 유지, `[verse]`/`[chorus]`/`[bridge]` 구조 태그만 삽입.
- 실패 분류: offline(연결 불가) / model_missing(tags에 없음) / error → 안내 후 원문 진행 허용.

### 2.4 분리 서버 :8771 (기존) — 테이크 분리·노래방 세트에 재사용

- `GET /api/separator/status` → `{busy, gpu}` · `POST /api/separator/separate` multipart `file` → `{ok, instrumental_path, vocals_path}` (15분)

## 3. ffmpeg 체인 스펙

### 3.1 녹음 캡처 (buildRecordArgs 확장)

```
-f dshow -i audio=<device> -ac 1 -ar 48000
-af [volume=<gain>,]astats=metadata=1:reset=1,ametadata=print:key=lavfi.astats.Overall.RMS_level:file=-
-progress pipe:1 <out.wav>
```
- gain≠1.0일 때만 volume 삽입, astats 앞(미터에 게인 반영).
- 레벨 프로브: 동일 체인, 출력만 `-f null -`.

### 3.2 반주 잘라내기 (buildAccompanimentCutArgs)

```
-y -ss <startMs/1000, 소수3자리> -t <durationMs/1000> -i <sourceAudioPath> -vn -c:a aac -b:a 192k <id>_acc.m4a
```

### 3.3 믹스 (buildMixArgs 확장)

```
[0:a]volume=<accGain>[b];[1:a]adelay=<d>|<d>,<vocalFilters>volume=<vocalGain>[v];[b][v]amix=inputs=2:duration=first:normalize=0[a]
```
- vocalFilters = [afftdn,][aecho=<preset>,] — 순서: 노이즈 제거 → 리버브 → 볼륨
- accGain/vocalGain: mixBalance b → acc=(1-b)*2 clamp 0~1.6, vocal=b*2 clamp 0~1.6 (0.5=둘 다 1.0)
- aecho 프리셋: karaoke `0.8:0.85:60:0.35` · hall `0.8:0.88:220:0.4` · studio `0.7:0.8:40:0.25`
- 반주 조각 사용 시 adelay=0, 구 테이크 폴백 시 adelay=alignOffsetMs.

## 5. 에러 정책 (사용자 문구는 전부 한국어)

| 상황 | 처리 |
|---|---|
| 작곡 게이트웨이 오프라인 | 즉시 실패: "작곡 서버(8774)가 꺼져 있어요 — SAW에서 compose_system\start.bat" |
| ACE 엔진 미기동 | 즉시 실패: "ACE-Step 엔진(:8001)이 꺼져 있어요 — SAW 트레이 또는 C:\ai-acestep\start_api_server.bat" |
| 8774 잡 404(서버 재시작) | 잡 실패 처리: "서버가 재시작되어 작업 기록이 사라졌어요. 다시 생성해 주세요." |
| BGM 서버 오프라인 | 즉시 실패 + start.bat 안내 |
| Ollama 오프라인/모델 없음 | 스낵바 안내(`ollama pull <model>`) + 원문 그대로 생성 계속 가능 |
| 분리 서버 busy | 대기 안내 문구(작곡은 게이트웨이 lease가 처리) |
| 반주 컷 실패 | 테이크는 유지, `반주 만들기` 재시도 버튼 |
| 로컬AI OFF에서 API 호출 | 403 `local_ai_disabled` |
| 취소 | 보컬곡=폴링 중단·잡 포기, BGM=응답 무시 — "서버 작업은 계속될 수 있습니다" 명시 |

## 6. 화면 스펙 요약

- **작곡 탭**: 상태 칩(작곡 서버/BGM 서버, 텍스트 병기) → 생성 폼 카드 → 진행 스트립(보컬곡=서버 detail 실시간+경과 / BGM=경과+불확정 바) → 생성 목록(행당 듣기·이름·등록·내보내기·삭제, 50px 타겟).
- **설정 신설 섹션**: 녹음(장치·볼륨·마이크 테스트) / AI 기능(로컬·클라우드 스위치+팝업) / 작곡(Ollama 모델명+모델 확인).
- **녹음 탭 확장**: 트랙별 듣기 버튼, 믹스 설정 다이얼로그, 파일로 내보내기.
- **비활성 규칙**: 흐림(0.4 오퍼시티)+클릭 시 스낵바 "설정에서 로컬AI를 켜면 사용할 수 있습니다" — 색만으로 구분하지 않고 라벨 유지.
