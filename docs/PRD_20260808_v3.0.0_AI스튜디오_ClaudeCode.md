# PRD — SingPromfter v3.0.0 "AI 스튜디오"

- 작성일: 2026-08-08
- 작성자: Claude Code
- 상태: 승인됨 (소장님 확정)
- 현재 버전: v2.8.3 → 목표: **v3.0.0** (MAJOR)

## 1. 개요

SingPromfter를 "노래를 부르는 앱"에서 **"녹음·믹싱·보컬분리·AI 작곡까지 하는 개인 AI 스튜디오"**로 확장한다. 모든 AI 기능은 SVIL AI Workstation(SAW)의 로컬 서비스를 사용하며, 기본값은 꺼짐(OFF)으로 두어 AI 없이도 기존 노래방 기능이 온전히 동작한다.

## 2. 배경·문제

- 현재 녹음은 마이크 WAV 하나만 남는다. 반주와 믹스를 각각 보관·공유할 수 없다.
- 키조절(변형본) 반주로 녹음해도 믹스는 원키 반주와 섞이는 잠재 버그가 있다.
- 마이크 입력 장치·볼륨을 앱에서 고를 수 없다 (첫 번째 장치 고정).
- 곡은 유튜브 가져오기로만 늘릴 수 있다. 자작곡·연습용 BGM을 만들 방법이 없다.
- SAW에 ACE-Step 1.5 터보(작곡 게이트웨이 :8774)와 MusicGen(BGM :8766), Ollama가 이미 구축되어 있으나 앱과 연결되어 있지 않다.

## 3. 사용자

- **주 사용자(소장님)**: 저시력 접근성 기준 필수(고대비 다크·큰 터치 타겟·색+텍스트 병행). 버스킹·연습·자작곡 창작을 한 앱에서.
- **AI 협업 에이전트**: MCP(sp_*)로 곡 등록·재생·작곡을 원격 제어.

## 4. 목표 / 성공 기준

| 목표 | 성공 기준 |
|---|---|
| 녹음 3트랙 확보 | 녹음 종료 시 보컬 WAV + 반주 조각 + (요청 시) 믹스가 각각 파일로 존재, 폴더 내보내기 3파일 |
| 키 일치 믹스 | 키조절 반주로 녹음한 테이크의 믹스가 같은 키로 들린다 |
| 입력 제어 | 설정에서 장치 선택·볼륨(0~200%)·마이크 테스트가 동작하고 재시작 후에도 유지 |
| 믹싱 스튜디오 | 밸런스·리버브 3종·노이즈 제거를 적용해 재믹스 가능 |
| AI 작곡 | 작곡 탭에서 BGM(30초~5분)·보컬곡(3~10분, 한국어 가사) 생성→재생→곡 등록까지 앱 안에서 완결 |
| 한글 프롬프트 | 한국어 스타일 설명이 Ollama(gemma4:12b)로 영어 태그로 다듬어지고, 실패해도 원문 생성 가능 |
| AI 게이트 | 로컬AI/클라우드AI 기본 OFF, OFF 시 관련 메뉴가 보이되 비활성, ON 전환 시 설치 안내 팝업 |
| 무결성 | AI 서버가 모두 꺼져 있어도 기존 기능(재생·프롬프터·가져오기 중 비AI 모드) 회귀 없음 |

## 5. 기능 요구사항

### 5.1 녹음 코어 (Phase 1)
- FR-1.1 녹음 시작 시 실제 재생 중인 오디오 파일 경로(키/템포 변형본 포함)와 재생 위치를 기록한다.
- FR-1.2 녹음 종료 직후 해당 파일에서 녹음 구간과 동일한 반주 조각을 잘라 별도 파일로 저장한다(ffmpeg -ss/-t).
- FR-1.3 믹스는 반주 조각 + 보컬을 t=0 기준으로 합친다. 반주 조각이 없는 구 테이크는 기존 방식으로 폴백.
- FR-1.4 테이크별 "파일로 내보내기": 사용자가 고른 폴더에 `{제목}_{일시}_보컬.wav / _반주.m4a / _믹스.m4a` 3파일 복사.
- FR-1.5 설정 '녹음' 섹션: 입력 장치 드롭다운(+새로고침), 입력 볼륨 슬라이더(0~200%, % 상시 표시), 마이크 테스트(실시간 레벨 바+상태 텍스트).
- FR-1.6 입력 볼륨은 캡처 시점에 적용되어 레벨 미터·저장 파일 모두에 반영된다.

### 5.2 믹싱 스튜디오 (Phase 2)
- FR-2.1 테이크별 믹스 설정: 보컬/반주 밸런스(0~100%), 리버브 프리셋(없음/노래방/홀/스튜디오), 노이즈 제거 ON/OFF.
- FR-2.2 믹스 설정은 테이크에 저장되고 "다시 합치기"로 재믹스한다.
- FR-2.3 (로컬AI) 테이크 보컬 분리: 스피커 소리가 섞인 녹음을 분리 서버(8771)로 정리해 순수 보컬 파일을 만들고 믹스에 사용할 수 있다.

### 5.3 작곡 (Phase 3~5)
- FR-3.1 상단 탭에 '작곡' 추가 (녹음과 가져오기 기록 사이).
- FR-3.2 생성 폼: 제목 / 모드(BGM·보컬곡) / 스타일 프롬프트(한국어 가능) / 가사(보컬곡) / 보컬 타입(여성·남성·듀엣·합창) / 장르 태그 / BPM(선택) / 길이 / 고급(seed·프리셋·모델 크기).
- FR-3.3 보컬곡은 작곡 게이트웨이(:8774, ACE-Step 1.5 터보) 잡 제출→상태 폴링(서버 detail·경과 표시)→완료 시 파일 확보. 길이 3~10분.
- FR-3.4 BGM은 BGM 서버(:8766, MusicGen)로 생성. 길이 30초~5분. 응답 즉시 파일 확보(서버가 이전 출력을 지우므로).
- FR-3.5 'AI 다듬기': 한국어 스타일 프롬프트를 Ollama로 영어 태그로 변환해 편집 가능한 미리보기에 채운다. 가사는 한국어 유지, 구조 태그([verse]/[chorus]) 삽입 옵션. 실패 시 안내 후 원문 그대로 생성 가능.
- FR-3.6 생성 목록: 재생/정지, 이름 바꾸기, 곡으로 등록(라이브러리 Song 생성), 파일로 내보내기, 삭제. 변주는 그룹으로 표시.
- FR-3.7 seed 변주: 같은 조건으로 3곡 연속 생성.
- FR-3.8 노래방 세트(로컬AI): 생성 보컬곡 등록 시 옵션으로 분리 서버로 MR 생성(슬롯2) + 가사 자동 싱크(LRC)까지 일괄 수행.
- FR-3.9 생성 BGM을 기존 곡의 빈 슬롯에 반주로 부착할 수 있다.

### 5.4 AI 게이트 (Phase 4)
- FR-4.1 설정 'AI 기능' 섹션: 로컬AI/클라우드AI 스위치, 기본 모두 OFF.
- FR-4.2 OFF→ON 전환 시 필요한 설치/서버 목록과 현재 온라인 상태를 보여주는 안내 팝업. [켜기] 확정 시에만 ON.
- FR-4.3 로컬AI OFF 시: 작곡 탭 비활성(보이되 클릭 불가, 클릭하면 안내 스낵바), 곡 추가의 AI 분리 옵션 비활성(+사유 텍스트), 서버 상태 칩 숨김·폴링 중단, API/MCP 경유 요청도 거부(local_ai_disabled).
- FR-4.4 클라우드AI: 1호 기능으로 클라우드 LLM 프롬프트 다듬기(DeepSeek, SAW 경유)를 검토하되 미확정 시 "향후 확장용" 예약 토글로 출시.

### 5.5 MCP/제어 API (Phase 6)
- FR-5.1 제어 서버에 작곡·녹음 라우트 추가, singprompter MCP에 sp_compose 계열 도구 추가.
- FR-5.2 로컬AI OFF 시 해당 라우트는 403 local_ai_disabled.

## 6. 비기능 요구사항

- **접근성**: 고대비 다크, 상태는 색+텍스트 병행, 터치 타겟 50px, 폰트 12px 이상 — 기존 AppTheme/AppConstants 준수.
- **오프라인 무결성**: AI 서버 전부 꺼져도 비AI 기능 정상. 네트워크는 loopback + LRCLIB만.
- **데이터**: recordings.json v2·compositions.json v1 — additive 스키마, 구버전 파일 자연 흡수. 산출물은 Documents/data 아래 자립 보관.
- **자원**: GPU 잡 동시성 1(가져오기·작곡 각각), 게이트웨이 VRAM lease에 순번 위임. 백그라운드 폴링은 로컬AI ON일 때만.
- **버전 규칙**: APP_VERSION·VERSION_HISTORY 갱신, 설정에 업데이트 히스토리 표시(기존 구조 유지).

## 7. 범위 제외
