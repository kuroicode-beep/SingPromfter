## 요약

10개 확장 기능(유튜브·가사싱크·피치·녹음·트레이닝)을 올리기 위한 기반을 정리했다. **새 기능은 최소화**하고 구조적 블로커 3건과 스키마 위험을 제거했다. 다만 연습 로그는 이력이 곧 가치이므로 **적재만 이번에 시작**했다.

## 해소한 블로커

### 1. 전체화면 프롬프터의 재생 위치가 멈춰 있던 문제
`prompter_navigation.dart`가 `position`/`duration`을 `MaterialPageRoute` 빌더에 **값으로** 넘겨, 라우트가 부모 `setState`로 리빌드되지 않아 전체화면에 살아 있는 위치가 없었다. 이제 `PlaybackController`를 넘기고 전체화면이 `ValueListenableBuilder`로 직접 구독한다.

### 2. 하이라이트 줄 이동이 속도를 무시하고 중복 구현되던 문제
90ms 타이머가 무조건 한 줄씩 넘겨(≈11줄/초) 속도 슬라이더가 무시됐고, 같은 로직이 `prompter_screen.dart`에 독립 중복돼 패널과 전체화면이 어긋났다. 위치 기반 **순수 함수**(`LyricsProgressService.estimatedLineIndex`)로 대체해 두 문제를 구조적으로 제거하고, `prompter_auto_scroll_service.dart`를 삭제했다.

### 3. Windows 위치 이벤트가 초당 4회뿐이던 문제
`PositionClock`이 이벤트 사이를 보간한다. 250ms 초과 오차는 즉시 스냅, 이하는 25%만 당겨 튐을 없앤다. `Ticker`로 구동하고 일시정지 시 멈춰 CPU를 아끼며, 500ms마다 `getCurrentPosition()`으로 보조 재동기화한다.

## 스키마 강화

- **직렬화기 통합**: `toJson()`이 `toMetaJson()`을 확장하도록 바꿔, 새 필드를 한쪽에만 넣어 조용히 누락되는 문제를 영구 차단
- **`songs.json` v2 봉투**: `{"schemaVersion":2,"songs":[...]}`. v1 맨 배열은 그대로 읽고 다음 저장 때 승격. 상위 버전은 한국어 메시지로 거부
- **백업 매니페스트 실제 검증**: 기존엔 `version`을 쓰기만 하고 읽지 않았다
- **트림 유실 버그 수정**: 백업 복원 시 `startMs`/`endMs`가 버려지던 기존 버그를 `BackingTrack.copyWith` 도입으로 수정
- `KoreanText` 초성 유틸 추출 + **질의어도 초성 정규화**(‘봄ㄴ’도 매칭)

## 추가된 사용자 기능

- **좌측 목록 검색**: 데드코드로 있던 검색 패널을 제어형으로 다시 만들어 활성화. 4종 필터(전체/즐겨찾기/반주 있음/최근 등록), 화면을 전환해도 검색어 유지
- **연습 기록 적재**: 30초 이상 재생하면 1회로 집계, 60초 이내 재재생은 병합, 일시정지 구간 제외. 설정 화면에 곡별 **횟수·총 시간·최근 연습일·주 사용 키** 표시
  - 저장: `data/practice_log.json` (봉투 형식, 곡 삭제와 무관하게 보존)
  - 키 표기는 `formatKeyLabel`로 통일 — 원키 / 2키 낮춤 / 1키 높임

### 소장님 확인이 필요한 수동 회귀 항목
GUI 상호작용이 필요해 자동 검증에 포함하지 못했다.
1. 전체화면 진입 후 **진행바가 실제로 움직이는지** (블로커 1)
2. 속도 슬라이더를 올리면 **하이라이트 줄 이동이 빨라지는지** (블로커 2)
3. 패널과 전체화면의 하이라이트 줄이 **같은 줄인지**
4. 예약 큐 자동 진행, 트림 시작/끝 지점
5. 기존 백업 zip 가져오기 — **트림값 보존**
6. 30초 이상 연습 후 설정의 "연습 기록" 반영
