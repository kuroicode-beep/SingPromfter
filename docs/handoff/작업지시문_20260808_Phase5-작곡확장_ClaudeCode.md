# 작업지시문 — Phase 5: 작곡 확장 (v3.0.0)

- 작성일: 2026-08-08 · 담당: Claude Code · 선행: Phase 4 완료

## 목표

seed 변주·노래방 세트(분리+자동 싱크가사)·기존 곡 부착·프리셋 활용을 완성한다.

## 작업 항목

1. **seed 변주**: compose_panel에 `변주 3개 생성` — 같은 요청으로 3잡 enqueue(각 seed=-1 랜덤, 공통 batchId=uuid). 목록에서 batchId 그룹 헤더로 묶어 표시.
2. **노래방 세트** (로컬AI, 보컬곡 전용): '곡으로 등록' 다이얼로그에 체크박스 `노래방 세트 만들기(MR 분리+가사 싱크)`
   - ① addSong(슬롯1=생성곡, lyrics) → ② 8771 분리 → instrumental을 `data/mp3/<제목>_mr2.mp3`로 복사, 슬롯2 트랙 추가(라벨 'AI MR') → ③ 기존 `autoAlignLyrics`(lyrics_align_service — 원곡·MR 쌍 필요, 분리로 쌍 확보) 실행 → LRC 부착.
   - 진행은 작곡 잡 큐의 후속 잡으로 표시(각 단계 statusDetail). 부분 실패 허용: 분리 실패 시 곡 등록까지는 유지+안내.
3. **기존 곡에 부착**: 생성 항목 메뉴에 `기존 곡에 반주로 넣기` — 곡 선택 다이얼로그(빈 슬롯 있는 곡) → 기존 트랙 추가 경로 재사용(파일 복사→BackingTrack 추가, 라벨 'AI BGM').
4. **프리셋 활용**: BGM 모드 프리셋 선택 시 recommended_duration을 길이 칩에 자동 반영(수동 변경 가능).

## 테스트

- 변주 batchId 그룹핑 로직(순수 함수면 단위 테스트), 나머지는 수동 시나리오.

## 완료 기준

- 변주 3개 그룹 표시 · 노래방 세트로 등록한 곡이 슬롯1(원곡)+슬롯2(MR)+싱크 가사로 프롬프터에서 바로 연습 가능 · 기존 곡 부착 동작 · analyze/test 통과.
