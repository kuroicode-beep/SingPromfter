# 완료 보고서 — v2.1.0 곡 추가 주 경로를 링크 기반으로 교체

작성일: 2026-07-28
작성자: Claude Code
기준: v2.0.0(`4b59b18`) → `2.1.0+1`

## 배경 — 방향 수정

앞선 업데이트를 **"기존 기능 유지 + 신기능 추가"** 로 만들었는데, 실제 의도는 **교체**였습니다. 그 결과 이런 구조가 됐었어요.

- `[곡 등록]` 버튼 → 기존 수동 방식(가사 txt + 반주 mp3 직접 선택)
- 유튜브 가져오기 → 별도 `가져오기` 탭에 격리, 가사도 따로 눌러야 붙음

즉 **새 주 기능이 뒤로 밀리고 옛 방식이 정문에 남아 있었습니다.** 이번에 정문을 바꿨습니다.

## 새 흐름 (주 경로)

```
[곡 추가] → 링크 붙여넣기 → 반주 처리 선택 → 가사 자동 체크
   ↓
메타 조회 → 내려받기 → (선택 시) AI 보컬 분리 → 가사 자동 부착 → 재생목록 등록
```

한 번의 입력으로 끝까지 갑니다. 중간에 사람이 개입할 일이 없습니다.

### 곡 추가 대화상자 (`add_song_dialog.dart`, 신규)
- **링크 입력이 첫 화면**. 클립보드에 유튜브 주소가 있으면 자동으로 채워 넣습니다
- 반주 처리 4방식(MR 그대로 / 원곡 / 보컬 줄이기 / AI 분리) 선택
- **가사 자동 가져오기 기본 켜짐**
- AI 분리를 고르면 분리 서버 상태를 그 자리에서 알려줍니다(꺼져 있으면 경고)
- 유튜브가 아닌 주소·빈 입력은 입력 단계에서 막습니다
- **파일로 직접 추가**는 하단 보조 링크로 남겼습니다 — 링크가 없는 곡용

### 파이프라인 확장
기존에는 다운로드 후 "가사는 비워 두고" 끝났는데, 이제 **가사 부착까지 한 작업 안에서** 처리합니다. 가사를 못 찾아도 곡은 정상 등록되고 "가사는 찾지 못함"으로 알려 줍니다.

완료 시 스낵바로 `"곡 제목" 추가 완료 · 가사 포함` 을 띄웁니다.

### 진행 상황을 홈으로
가져오기가 주 경로가 됐으니 진행 상황도 홈에서 보여야 합니다. **홈 상단에 진행 스트립**(제목·단계·진행률·취소)을 추가했습니다. 진행 중인 작업이 없으면 아무것도 그리지 않습니다.

`가져오기` 탭은 **`가져오기 기록`** 으로 이름을 바꾸고 기록·재시도용 보조 화면으로 내렸습니다.

### 문구 정리
- 상단 버튼: `곡 등록` → **`곡 추가`**
- 빈 목록 안내: "상단 [곡 추가]에 유튜브 링크를 붙여넣으면 반주와 가사까지 자동으로 준비됩니다"
