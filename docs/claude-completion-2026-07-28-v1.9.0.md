# 완료 보고서 — v1.9.0 목록 관리 강화

작성일: 2026-07-28
작성자: Claude Code
기준: v1.8.0(`0377bcf`) → `1.9.0+1`

## 구현 내용

### 정렬 — 필터와 축을 분리
`SongListFilterMode`에 정렬을 끼워 넣으면 세 곳의 호출부가 모두 꼬이므로 **`SongSortMode`를 별도 축**으로 만들었습니다.

- 제목순 / 최근 등록순 / **많이 부른 순** / **덜 부른 순**
- 연습 횟수는 v1.3부터 쌓인 연습 로그에서 가져옵니다 — "덜 부른 순"은 손이 덜 간 곡을 찾는 데 씁니다
- 횟수가 같으면 제목순으로 안정 정렬해 순서가 흔들리지 않습니다

### 라이브러리 정리 도구
소프트 삭제 설계상 파일이 남고, 단계마다 디렉터리가 늘어(txt·mp3·lrc·recordings·cache·tmp) 찌꺼기가 쌓입니다. 설정에 **라이브러리 정리**를 추가했습니다.

점검 항목:
- **사용하지 않는 파일** — 어느 곡도 참조하지 않는 반주·싱크 가사 파일
- **파일이 없는 곡** — 곡 목록엔 있는데 실제 파일이 사라진 경우
- **제목이 겹치는 묶음** — 대소문자·앞뒤 공백 무시하고 탐지

정리는 **고아 파일과 임시 항목만** 지웁니다. 곡 목록은 건드리지 않고, 파일 없는 곡·중복 제목은 알려만 드립니다(직접 판단할 문제라서요). 실행 전 무엇을 지울지 확인 대화상자를 띄웁니다.

디스크 비교 로직(`LibraryAudit.compare`)은 **순수 함수**라 파일시스템 없이 테스트합니다.
