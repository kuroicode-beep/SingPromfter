# 완료보고서 — SingPromfter v3.0.0 "AI 스튜디오"

- 날짜: 2026-08-08 · 작업자: Claude Code · 브랜치: claude/vocal-composition-features-9646eb
- 범위: PRD_20260808_v3.0.0 전체 (Phase 0~7 구현 완료, Phase 8~9 릴리스·마무리 진행)

## 요약

노래방/프롬프터 앱을 녹음·믹싱·보컬분리·AI 작곡까지 하는 "개인 AI 스튜디오"로 확장하는 메이저 업데이트. 모든 AI 기능은 SAW 로컬 서비스를 쓰며 로컬AI/클라우드AI 스위치(기본 꺼짐)로 게이트된다.

## 구현 내역 (Phase별)

### Phase 0 — 문서 스위트
PRD·기술 스펙·아키텍처·로드맵·Phase별 작업지시서 6부 작성, Outline 위키 갱신(낡은 "HTTP API 없음" 아키텍처 문서 교체 + v3.0.0 PRD·로드맵 문서 신설).

### Phase 1 — 녹음 코어
- 녹음 시 실제 재생 파일(키/템포 변형본 포함)·재생 위치를 테이크에 기록 (`PlaybackSnapshot.activeAudioPath`)
- 녹음 종료 직후 반주 구간을 잘라 자립 보관 (`<id>_acc.m4a`, ffmpeg -ss/-t)
- 믹스를 반주 조각+보컬 t=0 정렬로 개편 — **변형본으로 녹음해도 원키 반주와 믹스되던 잠재 버그 해결**
- 파일로 내보내기: `{제목}_{일시}_보컬.wav/_반주.m4a/_믹스.m4a` 3파일
- 설정 '녹음' 섹션: 입력 장치 선택(새로고침)·입력 볼륨 0~200%(캡처 시점 게인, 미터 반영)·마이크 테스트 레벨 바
- recordings.json v1→v2 (additive), remove 시 부속 파일 누수 수정

### Phase 2 — 믹싱 스튜디오
- 테이크별 믹스 설정 다이얼로그: 밸런스(mixGains, 0.5=현행 유지)·리버브 3종(aecho 노래방/홀/스튜디오)·노이즈 제거(afftdn)·다시 합치기(임시 파일→교체로 기존 믹스 보존)
- 테이크 보컬 분리(8771): 스피커 녹음의 반주 제거 → `<id>_sep.wav`, 이후 믹스에 정리본 사용

### Phase 3 — 작곡 인프라
- `SongComposeClient`(8774 게이트웨이, ACE-Step 1.5 터보): 잡 제출→5초 폴링(서버 detail·VRAM 순번 실표시)→/output 확보
- `BgmComposeClient`(8766 MusicGen): 블로킹 생성→즉시 다운로드(서버가 이전 산출물을 지우는 정책 대비)
- `OllamaClient`(gemma4:12b 기본): 스타일 다듬기·가사 구조 태깅, offline/model_missing 분류 — 실패해도 원문 생성 진행
- Composition 모델 + data/compose 저장소(schemaVersion 1) + ComposeJobController(동시성 1, 취소=클라이언트 포기)

### Phase 4 — 작곡 UI + AI 게이트
- 상단 탭 '작곡' 신설: 생성 폼(제목/모드/스타일 프롬프트/가사/보컬 타입/장르/BPM/길이/고급 seed·프리셋·모델 크기) + AI 다듬기(편집 가능한 미리보기) + 진행 스트립 + 생성 목록(듣기·이름·등록·부착·내보내기·삭제)
- 로컬AI/클라우드AI 스위치(기본 OFF): 켜기 안내 팝업(구성요소·시작 방법·현재 상태), OFF 시 작곡 탭 흐림+안내 스낵바, 곡 추가/트랙 추가의 AI 분리 옵션 비활성, 서버 폴링 중단, API/MCP 403

### Phase 5 — 작곡 확장
- seed 변주 3개(batchId 묶음 표시) · 노래방 세트(등록→AI 분리 MR 슬롯2→균등 배치 LRC→DSP 오프셋 보정) · 생성 BGM을 기존 곡 빈 슬롯에 부착 · 8766 프리셋(추천 길이 자동 반영)

### Phase 6 — MCP/제어 API
- 라우트: POST/GET /api/compose · GET /api/compose/jobs · cancel/retry/register(karaokeSet)/DELETE · GET /api/recordings
- MCP 도구 7종: sp_compose·sp_compositions·sp_compose_jobs·sp_compose_cancel·sp_compose_register·sp_compose_delete(confirm)·sp_recordings
- /api/state 확장: activeComposeJobs·localAiEnabled·compose/bgm 서버 상태

### Phase 7 — QA·버전
- `flutter analyze` 0 이슈 · `flutter test` **618개 전체 통과** (신규 테스트 ~46개: 컷/믹스 체인·게인·프로브·스키마 v2·클라이언트 body 빌더·Ollama 파서·큐 로직·LRC 빌더·라우터 게이트)
- `flutter build windows --release` 성공 · 실행 스모크: 부팅 후 `GET /api/state` → version 3.0.0·localAiEnabled false·"로컬AI 꺼짐" 라벨 확인
- 버전: APP_VERSION 3.0.0 + 히스토리, pubspec 3.0.0+1

## 알려진 제약

- 취소는 클라이언트 포기 — 서버 측 생성은 계속될 수 있음(UI 명시)
- 생성 보컬곡 LRC는 균등 배치+DSP 보정이라 근사치(whisper 정밀 싱크는 다음 버전 후보)
- 구버전 앱은 recordings.json v2를 읽지 않음(기존 버전 가드 정책 동일)
- 클라우드AI 스위치는 예약(현재 기능 없음 — 팝업에 명시)
