## 1. v5.6.0 — AI 기능 전체 토글

### 문제

`localAiEnabled` 토글은 있었지만 게이트가 절반만 걸려 있었다. 꺼도 **가사 다시 생성·
음정 체크·AI 보정·DeepSeek 검증·분리 서버 상태 칩(60초 폴링)** 이 그대로 살아 있어
눌러야 실패했다. `cloudAiEnabled`는 아무 데서도 읽지 않는 죽은 스위치였다.

### 한 일

| 항목 | 내용 |
|---|---|
| 마스터 스위치 | `aiEnabled` 신설. 파생 게터 `localAiActive`/`cloudAiActive`만 읽게 통일(raw 필드 참조 12곳 치환) |
| 마이그레이션 | 옛 설정에 키가 없으면 하위 둘 중 하나라도 켜져 있었으면 승계 — 업데이트 후 AI가 통째로 사라지는 사고 방지 |
| 정책 단일화 | `lib/utils/ai_gate.dart` — 진입점별 숨김/라벨을 한 곳에서 결정 |
| 누락 게이트 5개 | STT 가사 다시 생성 · 음정 체크 · AI 보정 · DeepSeek 검증 · 분리 서버 칩 |
| 제어 API 방어선 | 컨트롤러 진입부 게이트 + `regenerate` 라우트 403 `local_ai_disabled` |
| 클라우드 연결 | `cloudAiEnabled`를 DeepSeek에 실제로 연결(그동안 죽은 스위치) |

### 숨김 정책 — 왜 탭만 다르게 두었나

| 진입점 | 정책 | 근거 |
|---|---|---|
| 작곡 **탭** | `(꺼짐)` 라벨 유지 | 고정 내비의 공간 기준점이다. 사라지면 외운 배치가 흔들리고 "왜 없어졌는지" 알 길도 없다 |
| 액션 버튼 3개 | 숨김 | 형제가 8~10개인 Wrap이다. "(꺼짐)"을 붙이면 줄만 밀리고 소음이 는다 |
| 상태 칩 | 숨김 + 폴링 정지 | 켤 수단 자체가 무의미. 위젯 트리에서 빠지며 타이머도 함께 멎는다 |
| DeepSeek 옵션 | 비활성 + 사유 | 비AI 옵션과 섞여 있다. 사라지면 "내가 켰던 게 왜 없지"가 된다 |

**오폭 방지가 최대 회귀 위험**이라 `AiGate`에 비AI 기능용 게터를 아예 만들지 않았다.
게터가 없으면 실수로 게이트를 걸 수 없다.

### 배지 아이콘화

## 2. v5.7.0 — 안드로이드

### 플랫폼 능력 게이트

`lib/utils/platform_capabilities.dart` 신설. `AiGate`가 **설정으로 켤 수 있는 것**을
다룬다면, 이쪽은 **켤 방법이 없는 것**을 다룬다 — 그래서 라벨도 달지 않고 감춘다.

| 능력 | 모바일 | 이유 |
|---|---|---|
| `hasExternalTools` | ✗ | 앱이 ffmpeg·yt-dlp를 실행할 수 없다(샌드박스) |
| `hasLocalAi` | ✗ | SAW 서버는 PC에 있다. 폰의 127.0.0.1은 폰 자신 |
| `hasDeviceRecording` | ✗ | 녹음이 ffmpeg DirectShow(Windows 전용)에 묶여 있다 |
| `hasControlServer` | ✗ | 백그라운드 수명 미보장 + PC에서 폰 루프백에 도달 불가 |
| `hasFreeFileExport` | ✗ | Scoped Storage — 임의 경로에 못 쓴다 |

`localAiActive`가 `hasLocalAi`를 곱하므로 **PC 백업을 옮겨 와 AI가 켜진 채로 들어와도
폰에서는 죽어 있다.**

**남는 탭**: 홈 · 검색 · 즐겨찾기 · 트레이닝 · 도움말 · 설정
**빠지는 탭**: 유튜브 · 녹음 · 작곡 · 가져오기 이력

설정에서도 AI·녹음 분류, 외부 도구 섹션, MR 내보내기 폴더를 감췄다. 빈 곡 목록 안내도
"상단 [곡 추가]에 유튜브 링크" → "PC 백업을 들여오세요"로 바꿨다(없는 버튼을 안내하던 문구).

### 릴리스 준비

- **INTERNET 권한**을 릴리즈 매니페스트에 추가 — Flutter 템플릿은 debug에만 넣어 둬서
  **개발 중엔 멀쩡하고 릴리즈 APK에서만 모든 네트워크가 죽는다**. `aapt dump permissions`로
  산출물에서 직접 확인했다.
- `key.properties` 기반 릴리즈 서명(없으면 debug 폴백). 키스토어 생성은 비밀번호가
  사용자 비밀이라 절차만 문서화했다.
- gradle 래퍼 추적 + `.gitattributes`로 LF 고정 + CI에 `build-android` 잡 추가.

## 3. v5.7.0 — PC 로컬 기준 동기화

**PC가 정본, 클라우드 없음.** 새 서버를 세우지 않고 제어 API(8772)에 `/api/sync/*`를 얹었다.

| 항목 | 설계 |
|---|---|
| 바인딩 | 기본 루프백. 동기화를 켤 때만 `anyIPv4`. 토글 즉시 재바인딩 |
| 원격 제한 | 루프백이 아닌 연결은 `/api/sync/*` 외 전부 **403** — 곡 삭제·재생 조작이 LAN에 열리지 않는다 |
| 인증 | `X-Sync-Token` = 페어링 코드(6자리). 서버를 켤 때마다 새로 만든다. `0·O·1·I·L` 제외 |
| 델타 | 반주 파일 **크기** 비교. mtime은 플랫폼마다 정밀도가 달라 판정에 안 쓴다 |
| 가사 | txt·lrc는 매니페스트에 본문을 실어 보낸다(수 KB라 왕복이 더 비싸다) |
| 역방향 | 폰 → PC는 **즐겨찾기·연습기록만**. push를 pull보다 **먼저** 부른다 |
| 탐색 | UDP 브로드캐스트(8773). 동기화가 켜져 있을 때만 응답, 응답에 코드 미포함 |

### 역방향에서 조심한 것

- 즐겨찾기는 **전체 목록이 아니라 폰에서 바꾼 것만** 보낸다. 전체를 보내면 PC에서 끈 별을
  폰이 되살린다.
- 연습기록은 **id 합집합** — 두 번 올려도 늘지 않는다.
- 올리기가 실패하면 `pendingFavorites`를 비우지 않아 다음 회차에 다시 시도한다.
- 바뀐 게 없으면 `songs.json`을 다시 쓰지 않는다(핫 파일).

### mDNS를 쓰지 않은 이유

Dart의 `multicast_dns`는 **조회 전용**이라 PC가 자신을 알릴 수단이 없다. 광고하려면
Windows 지원이 불확실한 별도 패키지가 필요하다. UDP 브로드캐스트는 `dart:io`만으로
양쪽이 되고 의존성이 늘지 않는다. 패키지는 추가했다가 제거했다.

## 5. 실측이 잡아낸 버그 2건

### ① 경로 방어의 오탐 — 말줄임표 제목이 통째로 404

파일명에 `..`가 있으면 무조건 막았더니 `아마도 그건.. - 최용준...mp3` 같은 곡의 반주가
전부 404로 실패했다(1회차 실패 3건). 막아야 하는 건 경로 구분자와 상위 디렉터리 참조지
점 두 개가 아니다. 진짜 방어선은 **등록된 반주 파일명과의 정확 일치**라 완화해도 약해지지
않는다. 수정 후 실패 0 확인, 회귀 테스트 추가.

### ② yt-dlp 노후화로 유튜브 다운로드 전면 실패 (사용자 신고)

"변진섭 – 숙녀에게"가 계속 실패한다는 제보. **업로드 3개 모두 403**, 2005년 옛 영상만
성공 → 특정 영상 차단이 아니라 전면 실패로 판정. `yt-dlp 2026.07.04 → 2026.08.19`
업데이트 후 같은 곡 정상 다운로드(mp3 6.76MB). `yt-dlp-ejs`는 0.8.0이 이미 최신.

> **판별법**: 최근 영상이 **전부** 안 되면 yt-dlp 노후화(7주면 이렇게 된다).
> **한 영상만** 안 되면 반복 시도로 인한 영상 단위 일시 차단 → 다른 업로드로 우회.

## 6. 함정 기록

- **Gradle 데몬 파일 잠금** — `AccessDeniedException`/`Unable to delete directory`로 반복
  실패하면 데몬이 핸들을 쥔 것. `JAVA_HOME` 지정 후 `gradlew.bat --stop` → `build/app`
  삭제 → 재빌드. 이번 세션에서 3회 발생, 같은 처방으로 해결.
- **gradle 래퍼 미추적** — Flutter 템플릿 .gitignore가 제외한다. CI·새 클론에서 안드로이드
  빌드가 불가능했다. `gradlew`는 리눅스에서 실행되므로 `.gitattributes`로 LF 고정
  (CRLF면 bad interpreter로 죽는다).
- **`dart format lib/`가 91개 파일을 재포맷** — 의도한 파일만 남기고 되돌렸다. 앞으로는
  건드린 파일만 지정해서 포맷할 것.
- **PC 빌드는 master에서 이뤄진다** — 워크트리에만 있는 코드는 `build_deploy.ps1`로
  빌드해도 반영되지 않는다(UDP 탐색이 안 붙어 30분 헤맸다). **병합 후 빌드**할 것.
- **adb push 경로** — Git Bash에서 `/sdcard/...`가 Windows 경로로 변환된다. PowerShell로
  호출하거나 `MSYS_NO_PATHCONV=1`.
- **PowerShell 리다이렉트로 스크린샷 저장 금지** — `adb exec-out screencap -p > x.png`가
  BOM·인코딩으로 깨진다. Bash로 저장할 것.
- **heredoc의 백슬래시** — bash heredoc이 `\\n`을 실제 개행으로 바꿔 Dart 문자열이 깨졌다
  (3회). `chr(92)+'n'`으로 조립할 것.

## 8. 사용자 확인 필요 (체크리스트 밖)

1. **Windows 방화벽 8772/8773 인바운드 허용** — 에뮬레이터는 호스트 별칭(10.0.2.2)으로

   손대지 않았다.

   `docs/architecture/안드로이드빌드_20260823_ClaudeCode.md` 참조.
3. **실기기 확인** — 저시력 기준 터치 타겟·글자 크기, 무대에서 아이콘 배지 인지.
4. **랜딩페이지 문구** — `site/index.html:433`의 "색만이 아니라 텍스트와 아이콘으로 함께"가
