  - 곡 스텝: 기존 ≥30초 재생 자동 체크와 멱등 수렴.
- 제어: 일시정지/재개(Space) · 섹션 다시시작(Home) · 건너뛰기 · 종료. 러너 카드는 인패널(모달 아님 — 곡 스텝 중 탭 이동 가능).
