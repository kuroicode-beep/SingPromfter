# 완료 보고서 — v1.8.0 트레이닝 센터

작성일: 2026-07-28
작성자: Claude Code
기준: v1.7.0(`516e10d`) → `1.8.0+1`

## 구현 내용

### 일일 보컬 루틴
표준 발성 교육 구조(호흡 → 워밍업 → 스케일 → 곡 적용)를 조사해 확인한 순서로 **30분 / 60분** 두 프리셋을 제공합니다. 소장님이 말씀하신 구성과 일치합니다.

| 단계 | 30분 | 60분 |
|---|---|---|
| 호흡 | 5분 | 8분 |
| 워밍업(립트릴·허밍) | 4분 | 7분 |
| 스케일링 | 6분 | 12분 |
| 루틴곡 | 8분 | 15분 |
| 목표곡 | 7분 | 15분 |
| 쿨다운 | — | 3분 |

각 단계에 실제 연습 방법 안내를 붙였습니다(예: "4박 들이마시고 8박 동안 '스' 소리로 내쉬기 ×4회").

**저작권**: 특정 유료 프로그램을 옮긴 것이 아니라 널리 통용되는 구조이며, 문구는 직접 작성했습니다. 로컬 상수로 두어 런타임 네트워크 의존이 없습니다.

### 자동 체크 — 이 기능의 핵심
루틴곡·목표곡 단계는 **실제로 그 곡을 30초 이상 연습하면 자동으로 체크**됩니다. v1.3에서 심어 둔 연습 로그가 재생을 감지해 표시하므로, 수동 체크만 있는 루틴 앱과 달리 "실제로 부른 것"만 인정됩니다. 호흡·스케일 같은 비재생 단계는 수동 체크입니다.

### 통계
- **연속 달성일(streak)** — 오늘부터 거슬러 올라가며 모든 단계를 마친 날을 셉니다
- **최근 7일 달성 일수**
- **오늘 진행** (완료/전체 단계)
- 곡별 누적 횟수·시간·주 사용 키 (v1.3부터 쌓인 데이터)

### 저장
`data/daily_goals.json` (봉투 형식). 날짜별 `{routineId, completedStepIds, note}`.

### 접근성
체크 상태를 색이 아니라 **체크박스 아이콘 + "완료" 텍스트**로 이중 표시. 모든 단계 행이 50dp 이상이고 한국어 Semantics 라벨(`... 완료/미완료`)을 답니다. 숫자는 모노.
