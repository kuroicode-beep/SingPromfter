## 진행 규칙

- 각 Phase는 작업지시서(docs/handoff)를 정본으로 구현하고, 종료 시 `flutter analyze`·`flutter test` 통과 상태를 유지한다.
- 커밋은 Phase 단위(기능이 크면 Phase 내 세부 단위 허용). 버전 범프는 Phase 7에서 한 번.
- 문서·위키는 Phase 0에서 선반영, Phase 7에서 최종 동기화.
