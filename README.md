# SingPromfter

저시력 사용자를 위한 노래 프롬프터 + 보컬 트레이닝 Flutter 데스크톱 앱입니다.

## 주요 기능 (v2.2.0)

### 곡 준비
- **곡 추가는 링크 하나로 통일** — 주소를 붙여넣으면 내려받기 → (선택) 보컬 분리 → 가사 자동 부착 → 목록 등록까지 한 번에 진행
- 반주 처리 방식 선택: 영상 오디오 그대로 / 원곡 그대로 / 보컬 감쇄 / AI 보컬 분리(로컬 SVIL 분리 서버)
- 가사 자동 검색(LRCLIB 싱크 가사) + 수동 `.lrc` 교체
- 가져오기 진행 상황을 홈 상단에서 표시, 실패 시 사유 안내

> 링크 가져오기는 **개인이 저작권을 소유한 링크에만** 사용해야 하며, 개인적 용도의 사용에 대한 책임은 사용자 본인에게 있습니다. 로컬 전용 기능이며 공유·업로드 경로는 제공하지 않습니다.

### 프롬프터
- 전체화면 프롬프터(가사 중심), 실시간 진행바
- 싱크 가사 표시 + 선행 오프셋(−3~+3초) 곡별 저장
- 7단계 글자 크기, 사용자 정의 pt, 줄 간격, 속도, 볼륨
- 접근성 프리셋: 기본 / 추천 / 무대
- 반주 슬롯(최대 3개) 선택 재생, 시작·끝 지점 트리밍, 재생 속도 0.5x~1.5x

### 연습
- 키(피치) 조절 — ffmpeg rubberband 오프라인 렌더 + 캐시, 템포 유지
- 녹음 + 녹음 보관함(코멘트·믹스다운)
- 일일 보컬 루틴(30분/60분) 목표 체크, 곡 재생 자동 체크
- 연습 로그 자동 적재 — 날짜·곡·시간·횟수·원곡 대비 키

### 라이브러리
- 검색(초성 지원), 즐겨찾기, 정렬(제목·최근·많이/덜 부른 순)
- 예약 큐, 드래그 재정렬, 자동 다음 곡 재생
- zip 백업 내보내기/가져오기, 라이브러리 정리(고아 파일·중복 제목)
- 삭제 실행 취소

## 외부 도구

앱에 번들하지 않고 사용자 환경의 도구를 호출한다.

| 도구 | 용도 | 없을 때 |
|---|---|---|
| `yt-dlp` | 링크 가져오기 | 곡 추가 대화상자에서 사유 표시 후 차단 |
| `ffmpeg` | 오디오 변환·피치 렌더·녹음 | 해당 기능만 비활성 |
| SVIL 분리 서버 (`127.0.0.1:8771`) | AI 보컬 분리 | 홈·대화상자에 "꺼짐" 표시 |
